# AGENTS.md — NixOS Config Flake

## Repository
Personal NixOS system configuration for host `xps` (x86_64-linux). Flake-based, uses `nixos-unstable`.

## Developer Commands

| Task | Command |
|------|---------|
| Apply config | `sudo nixos-rebuild switch --flake .#xps` |
| Build without switching | `sudo nixos-rebuild build --flake .#xps` |
| Check flake | `nix flake check` |
| Format all `.nix` files | `nix fmt` (uses alejandra) |
| Build install ISO | `nix build .#nixosConfigurations.xps-iso.config.system.build.isoImage` |
| Run disk partitioning (install only) | `sudo nix run .#disko -- --mode disko ./hosts/xps/disko.nix` |

## Architecture

- **`flake.nix`** — entrypoint. Defines `nixosConfigurations.xps` and `xps-iso`.
- **`hosts/xps/`** — host-specific config.
  - `configuration.nix` — top-level host config (imports `hardware-configuration.nix` and `disko.nix`).
  - `hardware-configuration.nix` — **auto-generated by `nixos-generate-config`**. Do not edit manually.
  - `disko.nix` — declarative disk layout (LUKS + BTRFS on `/dev/nvme0n1`).
- **`modules/`** — reusable NixOS modules imported by `flake.nix`.
  - `core.nix` — bootloader, networking, SSH, experimental features, impermanence mount.
  - `programs/programs.nix` — aggregator; imports individual program modules.
  - `desktop/xfce.nix`, `audio.nix`, `localization/frenglish.nix`, `users/cookiegigi.nix`, etc.

## Impermanence + Ephemeral Root

- `/` is a tmpfs (size 4G, reboots wipe it).
- Persistent data lives on BTRFS subvolume `@persist` mounted at `/persist`.
- `modules/core.nix` and `modules/users/cookiegigi.nix` declare what persists via `environment.persistence."/persist"`.
- **Implication**: Any new stateful paths (dotfiles, data dirs) must be explicitly added to persistence config or they vanish on reboot.

## Disko

- `disko.nix` is only for initial installation/repartitioning, **not** part of regular rebuilds.
- It declares `/dev/nvme0n1` with LUKS (`cookieluks`) and BTRFS subvolumes `@persist`, `@nix`, `@snapshots`.
- Do not change disk device paths here unless the target hardware actually changed.

## ISO Config

- `xps-iso` extends the live CD installer with the real `xps` config + disko module + `modules/iso.nix` overrides.
- `modules/iso.nix` forces `systemd-boot` off and limits supported filesystems.

## Style & Conventions

- Formatter: **alejandra** (enforced via `nix fmt`). Run before committing.
- Use `nixpkgs.lib.nixosSystem` modules pattern; no custom overlays or packages defined.
- Keep host-specific settings in `hosts/xps/`. Keep reusable modules in `modules/`.
- `.gitignore` ignores `result` and `*.qcow2` (build outputs).

## Warnings

- `hardware-configuration.nix` header says "Do not modify this file!" — respect it.
- `boot.kernelPackages = pkgs.linuxPackages_latest` in `core.nix` — this tracks the latest kernel, which can occasionally cause regressions.
- No CI, tests, or pre-commit hooks exist. Verification is manual (`nix flake check`, `nixos-rebuild build`).
